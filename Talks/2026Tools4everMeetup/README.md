# Tools4ever Meetup - Building your own MCP server

This is a talk I gave at [Tools4ever Meetup](https://www.tools4ever.nl/events/tools4ever-meetup-2026/). The talk was in Dutch.

## Talk Title

### Building your own MCP server

## Abstract

Op 16 april organiseren we een Meetup op ons kantoor in Baarn. Tijdens deze sessie duiken we samen met Stuart van der Lee in het Model Context Protocol (MCP). Dit protocol wordt vaak omschreven als de USB-C voor AI: een krachtige schakel tussen echte systemen en LLMs. Maar hoe begin je met MCP en, belangrijker nog, hoe bouw je je eigen MCP server?

In deze sessie bouwen we stap voor stap een MCP server met de MCP C# SDK. We laten zien hoe je tools, prompts en resources opzet en hoe je deze gebruikt met je eigen AI-agent in Microsoft Foundry. Zo krijg je een praktisch en helder beeld van wat MCP is en wat je ermee kunt doen.
